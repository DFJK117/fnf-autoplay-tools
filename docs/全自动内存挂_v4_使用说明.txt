================================================================================
全自动内存代打器 v4.0 —— 进曲自动检测内存, 直接开打, 支持多K
================================================================================

【和之前版本的区别】
- v2.4 开环: 按F5猜起点 + 本地时钟, 会漂, 要手动调延迟
- v3   闭环: 读 songPosition 时钟 + 导入谱面, 零漂移但要选谱面
- v4   内存挂: 直接读游戏内存里的 Note 对象, 用【引擎自己算好的判定窗口】发键
              → 零导入谱面、零F5、零调延迟、进曲自动开打、天然支持多K

【原理(为什么是"正规外挂"不是回放/botplay)】
NF 实际编译的是 codename 引擎分支, 音符对象 = codename.funkin.game.Note,
挂在 StrumLine 上。hxcpp 非压缩/分代 GC 下, 每个 Note 对象头 8 字节是同一个
vtable 指针 —— 一首歌几百上千个 Note 就是几百上千个相同指针, 这是稳定的扫描锚点。

引擎每帧自己根据 songPosition 算好每个 Note 的 canBeHit(是否进入判定窗口)
和 wasGoodHit(是否已打)。程序只读这两个引擎算好的结果:
    canBeHit == true 且 wasGoodHit == false 且 属于玩家侧 → 立即发一个真实键盘键
发的键走 SendInput 系统级注入, 和真人按 DFJK 走完全相同的判定管线。
不是回放(没有录像文件)、不是botplay(没改游戏自动判定标志)、不修改游戏内存。

【怎么用】
1. 打开游戏, 进入任意一首歌(曲目要真的在播放, 不能停在菜单/暂停)
2. 运行 全自动内存挂v4.exe
3. 点【▶ 启动全自动(等待进曲)】
4. 程序自动: 找游戏进程 → 扫内存定位 Note 对象群 → 推断字段偏移 →
   识别玩家侧 strumLine → 开始按。全程不用按F5、不用选谱面。
5. 曲终/换曲会自动继续(每0.6秒重扫地址应对GC); 点【■停止】退出。

【多K支持】
- 自动从 noteData 和 strumLine 成员数推断键数, 键位按引擎 ClientPrefs.keyBinds:
    4K=D F J K  5K=D F 空格 J K  6K=S D F J K L  7K=S D F 空格 J K L
    8K=A S D F J K L ;  9K=A S D F 空格 J K L ;  10K=A S D F V N J K L ;
  FOJC 的 13K/18K 用字母+数字键扩展(见程序内"键位方案")。
- 如某首曲识别键数不准, 用【强制键数】手动指定(0=自动)。
- "键位方案"可切 引擎默认 / 经典4K(无空格)。

【排查】
- 一直"等待游戏进程": 游戏没开, 或进程名不含 NovaFlare(本程序找 novaflare 关键字)
- "还没进曲/没扫到 Note 群": 确认曲目在播放(不是暂停/结算画面)
- 扫到了但打不准/大量miss: 发日志, 可能需要校准 canHit 偏移或强制键数
- 只打对手不打玩家: 玩家侧strumLine识别判据需调, 发日志
