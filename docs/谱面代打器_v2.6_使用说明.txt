谱面代打器 v2.6 —— 引擎/模组自动扫描 + 精确按键防抽搐版
==========================================================
这版把你说的"能选模组、能列出本机装了哪些 FNF 引擎"做进来了。
本质还是老方法：真键盘 SendInput 模拟按键，走游戏正常判定。

【v2.6 新增：三级联动，不用再手动找谱面 JSON】
1. 启动后自动扫描本机所有 FNF 引擎（约 10 秒，后台扫描不卡界面）。
   判据：目录同时含 *.exe 和 assets/（且 assets 下有 FNF 特征目录），
   自动排除 WorkBuddy / 豆包 / 浏览器 这类无关程序。
   本机实测扫到 6 个引擎：NF(NovaFlare) / Leather / Kade×2 / QT / Indie Cross。
2. "引擎"下拉：选一个引擎。引擎名带父目录区分同名 bin。
3. "模组"下拉：列出该引擎 mods/ 下所有模组，第一项是"<引擎内置>"。
   例：Leather 下有 DK_Duet / Debug Songs / Template Mod。
4. "谱面"下拉：列出该引擎或模组下所有可打谱面，格式"曲名 / 难度 [音符数]"。
   例：DK_Duet → double kill / hard [2800 音符]。
   选中即自动载入，noteType 列表和"当前将按"同步刷新。
5. 也可以继续用"手动选…浏览…"直接选任意 JSON（老方法保留）。
6. 换引擎/模组后如果想重扫谱面，点"刷新引擎"重新来一遍。

【v2.5 继承：防抽搐三件套（快速按键不再乱跳）】
1. 旧 Timer 误伤：改成带编号的释放队列，旧计划到点自动作废，
   绝不松开刚按下的新键。快速同键连按 = 按下-松开-按下（不再吞键）。
2. 假 1ms 睡眠：把 Windows 时钟 tick 提到 1ms，临近音符高精度忙等。
3. 8 轨撞键：同一时刻的键合并成一次按下，不再自己打自己。

【怎么用】
1. 双击 EXE → 等引擎扫描完 → 依次选 引擎 / 模组 / 谱面。
2. "代打目标"：玩家侧（默认，只按玩家 type）/ 对手 / 全部。
3. 键位默认 D F J K，4 个键名可改（支持 SPACE、方向键、F1~F12）。
4. noteType 默认全勾，可取消不想打的。
5. GO 瞬间按 F5 或点"▶ 开始代打"——程序自动把焦点切回游戏。
6. F5 再按=停止；Esc=急停。

【实时调参】
- Ctrl + ↑ ：延迟 +2ms（提前更多）；Ctrl + ↓ ：-2ms（提前更少）
- "按住ms"：默认 38。抽搐/漏判 → 加大到 60~80；糊键拖尾 → 减到 25。
  别低于 12ms（游戏一帧约 16.7ms，太短可能整帧采不到）。

【判断在不在生效】
- 日志实时刷"按下 轨X→Y [type] @时间ms"。
- 顶栏显示 offset / hold / 高精度时钟开。
- 按了没反应：确认游戏窗口在前台（焦点被抢时键会发给抢焦点的窗口），
  点一下游戏窗口再按 F5。

【文件】
- 谱面代打器_F5_v26.exe  主程序
- autoplay_v26.py        源码

【边界 / 实话】
- 扫描是启动时一次性快照：新装了引擎/模组要点"刷新引擎"。
- 谱面按内容识别（含 sectionNotes/notes 且音符数>0），个别特殊格式可能漏列，
  漏了就用手动浏览。
- 按键逻辑/扫描器/防抽搐都过了单测和本机真实扫描验证；
  完整进曲实测本机 RDP 焦点受限做不了，需你在自己环境点一次 F5 确认。
