============================================================
全自动外挂 v5 —— 外部 EXE，真键盘，内存时钟闭环
============================================================

【这跟 Lua 是完全不同的东西】
- Lua 版 = 塞进游戏的 Bot Play，判定被强制全 Sick，排行榜可能不计成绩
- 本 EXE = 独立程序，读游戏内存时钟，SendInput 发真实键盘事件，
  判定走游戏正常流程（能上排行榜），不是 Bot。

【文件】
可执行文件：全自动外挂v5.exe（双击运行）
源码：fullauto_v5.py

【原理】
hxcpp 把 Conductor.songPosition 编译成游戏 exe 数据段的全局 double。
本程序启动后扫描游戏进程内存，找「随墙钟 1:1 增长、在主 exe、排除显卡
驱动区」的 double = songPosition，锁定地址。之后每 1ms 读它的值，
当它 >= 音符 strumTime 就发真键。闭环，零漂移，不用 F5、不用调延迟。

【怎么用】
1. 打开游戏，进一首歌让它「正在播放」（不能停在暂停菜单/主菜单）
2. 双击 全自动外挂v5.exe
3. 点「浏览…」选谱面 JSON
   - 路径一般在 游戏目录/mods/<mod>/songs/<歌名>/<难度>.json
4. 设键数（4K/7K/13K 都行）+ 键位（默认 D F J K，空格用 SPACE）
   点「应用」
5. 点「▶ 自动锁定并开打」
   - 首次会扫描几秒锁定时钟，锁定后自动开打
   - 锁定结果存 songpos_lock.json，下次同版本游戏启动直接读缓存秒开
6. F5 急停；Ctrl+↑ / Ctrl+↓ 微调偏移（±2ms/档）

【已验证的部分（静态 + 合成测试，全过）】
- v5 自检 --selftest：谱面解析 / 多K键位 / 56键全键盘VK表 / SendInput 结构
- 时钟锁定算法合成测试：1:1 增长 double 能精确锁定，静态噪声全排除
- 缓存数值校验：正确排除 0 值和停滞值
- EXE 打包成功、GUI 冒烟测试正常启动不崩溃

【必须说清楚的实测边界】
本程序的核心逻辑（SendInput、谱面解析、多K、时钟锁定算法）已验证正确，
但「对真实游戏进程锁定 songPosition」这一步没能在本机实测通过：
本机的 RDP 会话下游戏无法正常启动（进程卡在 32~52KB、不创建窗口），
之前唯一起来的一次又停在暂停菜单、且窗口焦点被豆包客户端抢占。
所以「锁定真实时钟」这一环需要你在自己正常进曲的环境里跑一次确认。
如果点开打后提示「✗ 没锁定」，说明当时歌曲没在播放或版本对不上，
让歌曲真正播放后再点一次即可。

【排错】
- 提示「没找到游戏进程」：先开游戏
- 提示「没锁定」：歌曲要在播放中，不能暂停/在菜单；首次锁定需几秒
- 打不准：Ctrl+↑↓ 微调偏移；或确认选的谱面/难度跟当前播放一致
- 锁错版本：删掉 全自动外挂v5.exe 同目录的 songpos_lock.json 重新锁
