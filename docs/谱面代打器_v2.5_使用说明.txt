谱面代打器 v2.5 —— 精确按键 / 防抽搐版
========================================
回退到老方法：模拟键盘输入（真 SendInput 事件，走游戏正常判定）。
不再用全自动/内存挂那套（那套已作废，不适合本机）。

【这次修了什么——"快速按键抽搐"的三个真凶】
1. 旧 Timer 误伤：v2.4 每个音符起一个定时松开线程，同键快速连按时
   上一发的定时器到点会把"刚按下的新键"松开，游戏看到 down-up-down
   乱跳 → 判定抽搐。v2.5 改成队列+唯一编号，旧计划到点自动作废，
   绝不碰新按键。单测已验证：快速同键连按 = 按下-松开-按下（不再吞键）。
2. 假 1ms 睡眠：Windows 默认时钟 tick 是 15.6ms，sleep(1ms) 实际睡 15ms，
   快速音符时机全飘。v2.5 把系统 tick 提到 1ms，临近音符用高精度忙等。
3. 8轨撞键：8 轨谱 lane0/lane4 映射到同一个键，同时触发就连按两次同键。
   v2.5 同一时刻的键合并成一次按下（取最长保持），不再自己打自己。

【怎么用（跟 v2.4 一样）】
1. 双击 EXE 启动。
2. "浏览…" 选谱面 JSON（Psych / Kade / psych_v1_convert 都支持）。
3. "代打目标"：
   - 玩家侧（默认）：只按归属玩家的 noteType
   - 对手 / 全部：检测所有 type
4. 键位默认 D F J K（4 键），改的话填 4 个键名点"应用键位"。
   支持 SPACE、字母、方向键、F1~F12 等。
5. noteType 列表默认全勾，可以取消勾选不想打的。
6. GO 瞬间点"▶ 开始代打"或按 F5 —— 程序自动把焦点切回游戏窗口。
7. F5 再按一次 = 停止；Esc = 急停。

【实时调参】
- Ctrl + ↑ ：延迟 +2ms（提前更多按键）
- Ctrl + ↓ ：延迟 -2ms（提前更少）
- "按住ms" 输入框：默认 38ms。
  * 抽搐 / 漏判（键没被游戏认到）→ 加大到 60~80ms
  * 快速连击糊在一起 / 长按拖尾 → 减小到 25ms
  * 注意别低于 12ms（游戏一帧约 16.7ms，太短可能整帧采不到）

【判断是不是真的在生效】
- 日志里每按一键都会打印 "按下 轨X→Y [type] @时间ms"，实时刷。
- 顶栏状态栏显示 "offset / hold / 高精度时钟(开)"。
- 如果按了没反应：确认游戏窗口在前台（焦点被别的窗口抢走时
  SendInput 会把键发给那个窗口）。点一下游戏窗口再按 F5。

【文件】

- autoplay_v25.py        源码
- 谱面代打器_F5_v25.spec 打包配置

【边界 / 实话】
- 本机 RDP 会话下游戏窗口焦点会被抢，实测环节我这边做不了完整进曲验证；
  按键调度逻辑、谱面解析、注入结构、防抽搐行为都过了单测和冒烟启动。
- 这是按固定谱面 + 本地计时发键，不是读内存全自动；
  歌曲速度/中途暂停重开会失步，重开请按 F5 停了再重新开。
