----------------------------------------------------------------
【重大发现】你的 NF 引擎原生 replay 系统
----------------------------------------------------------------
位置：windows/replays/<mod>/<歌曲>/<难度>/<时间戳>.rsd  (+ .txt 元数据)
格式：.rsd = AES-256-CBC 加密的 JSON（密钥就在引擎源码 EncryptUtil.hx）
明文结构：
  {
    stateRecord: { 歌曲/难度/速度/键位/游戏设置... },
    frameRecord: [
      { time: 毫秒, songSpeed, playbackRate,
        pressKey: ["D","F"],      ← 这一帧按下哪些键
        releaseKey: [...],        ← 这一帧松开哪些键
        noteJudgments: [{rating:"sick", strumTime, noteData, hitDiff}] }
    ]
  }
关键：引擎回放时把 pressKey/releaseKey 写进 FlxG.keys 的真实按键状态，
然后调用 PlayState.keyPressed() / keyReleased() / goodNoteHit() ——
【和真人按 D/F/J/K 走的是同一个函数】，不是 botplay，不是作弊加分。
（证据：source/games/backend/Replay.hx 的 handleInput() 第 258 行起，
 以及 source/games/PlayState.hx 的 replayApplyInput() 第 4251 行起。）

这直接回答了你上一轮的问题：replay 在你这个改版引擎里【确实能用】，
我上次说"FNF 没有 replay 消费端"是对通用 PE/NF 的判断，没算到你的
定制引擎有这套系统。我纠正。

================================================================
【第一档】全自动 = Replay 生成器（推荐，最稳）
================================================================
做法：
  1. 运行 全自动Replay生成器.exe
  2. 选 mod → 选谱面 → 选一个"真实 replay 当模板"（对齐曲目参数/键位）
  3. 确认歌曲ID/难度 → 点【生成】
  4. 工具自动生成 perfect replay（每个音符都在正确时刻按键，
     判定全 sick），并复制到游戏 replay 目录
  5. 进游戏 → Freeplay → 回放列表选它 → 引擎自己打完，全程无 miss

优点：
  ✓ 真正全自动：不用导谱面到外挂、不用按 F5、不用调延迟、不用开着程序
  ✓ 引擎原生：走真人判定管线，不是 botplay，评分/判定完全真实
  ✓ 稳定：不碰内存、不受 GC/地址变化影响，replay 文件是静态的
  ✓ 可复现：同一份 replay 每次回放结果一样

说明：
  - "state 模板"用你已有的真实 replay（19:16 那份 OLD 就能用），
    这样 songSpeed=3、键位、游戏设置全部自动对齐，不用手填。
  - 默认侧=玩家（只按 lane 0-3 的玩家音符），lane 4-7 是对手/独唱不按。
  - 命中的音符全部 sick，是"完美成绩"的 replay。

================================================================
【第二档】半自动 = 闭环代打器 v3（当场打，不生成文件）
================================================================
做法：运行 闭环代打器_v3.exe，选谱面 → 让游戏处于【播放中】→
点【自动锁定并开打】。程序读游戏内存 songPosition 闭环驱动真键盘。

优点：
  ✓ 当场打，不用生成/切换 replay 文件
  ✓ 零漂移、不用调延迟
注意：
  - 需要游戏正在播放一首歌才能锁定地址（暂停/结算界面锁不到）
  - 仍在验证阶段：本机只在暂停态验证了机制，播放态实测需你本机配合

----------------------------------------------------------------
两档怎么选：
  - 想要稳定、可复现、不用每次开外挂 → 第一档（replay）
  - 想当场打、不想生成文件 → 第二档（闭环注入）
