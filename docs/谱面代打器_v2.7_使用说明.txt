谱面代打器 v2.7 —— 分轨修正版（2026-11-21）
=============================================

这版只干一件事：修掉 v2.6 "一人唱俩"（玩家模式把对手的音符也按了）。

【v2.6 到底错在哪】
1. 玩家模式判定只看 noteType：对手轨道里"没标 type 的普通音符"
   全被当成玩家的按了 —— 对手轨有 1500+ 个这种音符，全部误按，
   听起来就是一个人唱俩。
2. 对手轨（lane 4-7）的归属推断公式还是反的：
   对手段（mustHitSection=False）里的 lane 4-7 被算成"玩家音符"。

【v2.7 怎么判归属】（优先级从高到低）
1. 5 列谱面（psych_v1_convert）：第 5 列显式归属 bool，直接用。
2. 带 mustPress 字段的 dict 谱面：直接用。
3. lane 4-7：一律对手（4K 代打玩家不可能用 4 以上的轨道）。
4. lane 0-3：按所在段的 mustHitSection。

【三种模式语义】
- 玩家（默认）：只按玩家轨/type 的音符 —— 对手轨零误按
- 对手：只按对手轨/type 的音符
- 全部：玩家 + 对手都按

【验证】
- 单测：DK 式 8 轨谱回归（玩家模式只按 lane0-3）
- 真谱面：double kill-hard 2799 音符，
  玩家轨/type 1223 / 对手轨/type 1576，玩家模式目标全在 lane0-3

【继承 v2.6/v2.5 全部】
- 引擎 → 模组 → 谱面 三级联动自动扫描（NF/Leather/Kade×2/QT/Indie Cross）
- 防抽搐三件套：heapq 释放队列 / 1ms 定时器 / 同键先松后按
- F5 启停、Ctrl+↑↓ 调延迟、按住时长可调（默认 38ms）
- 老的"手动浏览 JSON"也保留

【用法】
1. 双击 exe，等它扫完引擎（几秒）
2. 下拉选 引擎 → 模组 → 谱面（或手动浏览 JSON）
3. 代打目标选"玩家"（默认就是）
4. 点游戏窗口一下，按 F5 开始；再按 F5 停；Esc 急停
5. 日志里会实时刷"按下 轨X→Y"，只该出现轨 1~4（玩家轨）；
   如果还想听对手唱，把代打目标切"对手"再按 F5

【抽搐/漏判微调】
- 按住时长加大到 60（抽搐/漏判）或减到 25（糊键）
- Ctrl+↑ 每次 2ms 提前，Ctrl+↓ 每次 2ms 推迟
