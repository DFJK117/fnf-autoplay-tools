谱面代打器 v2.4 —— 使用说明
======================================================
v2.4 修复（相比 v2.2/2.3）：
  1. 分轨改按 noteType 归属判定（不再用 mustHitSection）：
     - 玩家模式（默认）：只按「玩家 type」音符
       玩家 type = 普通音符(无type) + 机制类(CupNote/Blue/Orange/Ink/Parry...)
     - 对手模式 / 全部模式：检测所有 type（玩家+对手全按）
     每个 noteType 勾选框前面标了 [玩家] / [对手]，一眼看清归属。
  2. 修「开了没用」：用按钮/F5 启动后，程序自动把焦点切回游戏窗口，
     否则 SendInput 的按键会发给程序自己，游戏收不到。
  3. F5 去掉「先点开始检测」门槛，谱面载入后任何时候按 F5 都能开/停。

======================================================
怎么用（傻瓜版）
======================================================
1. 双击 谱面代打器_F5_v24.exe 打开程序
2. 点「浏览…」选谱面 JSON（FNF 的 *-hard.json 之类）
   - 载入后会显示：N 音符（玩家type X / 对手type Y），M 种 noteType
   - 下面列表勾你要按的 type，前面 [玩家]/[对手] 是归属
3. 选「代打目标」：
   - 玩家侧（默认）→ 只按玩家 type
   - 对手 / 全部 → 检测所有 type
4. 看「当前将按：N / 总数」确认数量对不对
5. 打开游戏，进曲目，在 GO 的瞬间按 F5 开始代打
   - 程序会自动把游戏窗口切到前台，不用手动点游戏
   - 也可以直接点程序的「▶ 开始代打」按钮
6. Ctrl+↑ / Ctrl+↓ 实时调延迟（每次 2ms，提前/推后）
7. F5 再按一次停止；Esc 急停（松开所有键）

======================================================
4 键位
======================================================
默认是 D F J K（对应左 下 上 右）。改成别的就填 4 个键名，比如 "A S W E"，
点「应用键位」。用的是虚拟键码，支持字母和数字和方向键名。

======================================================
延迟校正
======================================================
Ctrl+↑ = +2ms（更早按），Ctrl+↓ = -2ms（更晚按）。
游戏显示判定偏移多少就调多少，状态栏实时显示 offset。

======================================================
常见问题
======================================================
Q：按 F5 没反应？
A：先载入谱面，看状态栏是不是「待机：玩家type X ...」。没载谱面按 F5 无效。

Q：显示「当前将按 0」？
A：noteType 一个都没勾，或当前目标侧没音符。点「全选」再试。

Q：解析失败？
A：支持四种格式：标准 PE/Kade {"song":{...}}、psych_v1_convert
   {"song":"歌名","notes":[...]}、strumTime 对象数组、sectionNotes 段。
   把报错文字记下来反馈即可。

Q：游戏收不到按键？
A：游戏和程序权限要一致（都为管理员或都为普通），UAC 会拦注入。
   v2.4 已自动切焦点，正常不会再有这问题。
